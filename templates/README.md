## How this project is built

This repo uses **The Forge Lite** — a Claude Code workflow that takes a feature from idea to shipped code, with state stored as Markdown plan files (no GitHub issues, no PR ceremony).

The pipeline is four phases:

```
/ponder  →  /forge  →  /temper  →  /seal
```

- `/ponder` — grill the idea, write a plan file under `.claude/plans/active/<slug>.md`.
- `/prototype` — fast-path, one-slice plan; skips the grill.
- `/forge` — implement the next queued slice in the active plan.
- `/temper` — review the latest shipped slice against its acceptance criteria.
- `/seal` — mark the plan done; move its file from `active/` to `done/`.

One operator command per phase. State lives entirely on disk under `.claude/plans/`.
